# Contributing / 参与贡献

## English

1. Fork the repository and create a focused branch.
2. Do not add real recordings, transcripts, employee names, customer data, or generated HR reports.
3. Add or update tests for behavioral changes.
4. Run `python -m unittest discover -s tests -v`.
5. Explain privacy, compatibility, and dependency impacts in the pull request.

## 中文

1. Fork 仓库并创建聚焦单一改动的分支。
2. 禁止提交真实录音、转译、员工姓名、客户数据或生成的人事报告。
3. 行为变更必须新增或更新测试。
4. 运行 `python -m unittest discover -s tests -v`。
5. 在 Pull Request 中说明隐私、兼容性及依赖影响。
