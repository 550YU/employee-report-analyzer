# Security and Privacy / 安全与隐私

## English

Do not report sensitive employee or customer data in a public issue. For a security vulnerability, contact the repository owner privately through GitHub.

This project processes potentially sensitive recordings and transcripts. Keep source media, generated reports, model caches, and temporary chunks outside version control. Review output before sharing. ASR and diarization are probabilistic and must not be treated as identity proof or an authoritative employment assessment.

## 中文

请勿在公开 Issue 中提交员工或客户敏感信息。若发现安全漏洞，请通过 GitHub 私下联系仓库所有者。

本项目可能处理敏感录音和转译内容。原始媒体、生成报告、模型缓存及临时分块均不应进入版本控制。分享前必须人工检查。ASR 和说话人聚类具有概率性，不能作为身份认证或权威人事评价依据。
